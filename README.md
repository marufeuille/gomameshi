# ごまめし

PFC（たんぱく質・脂質・炭水化物）を軸に毎日の食事を記録する、個人用の食事ログアプリ。
Muse の Space（TypeScript web artifact）として動作し、記録や食品マスタの管理は Muse との対話からも行える。

## 名前について

「ごま」は、このアプリを作った AI エージェント（Muse）の名前。
そのごまが日々付けてくれる食事の記録、という意味で「ごまめし」。

## できること

- 食事ログ：朝食・昼食・夕食・間食ごとの記録、外食フラグ、メモ
- 食品マスタ：日本食品標準成分表ベースのデータ＋市販品の成分表示から登録した食品（出典つき）
- レシピ：材料から栄養価を計算して登録、取り込み対応
- 摂取グループ：よく使う食品のセット（例：プロテイン＋牛乳）をまとめて記録
- 日次サマリ：カロリーと PFC をその日の目標と対照して表示（目標は履歴つきで変更可）
- AI アシスト：成分表示の写真読み取り、食品リサーチの下調べ

## 構成

- `client/` — React クライアント
- `server/src/actions.ts` — サーバーアクション
- `server/src/schema.ts` — DB スキーマ
- `server/src/foodTableData.ts` — 食品標準成分表データ
- `drizzle/` — マイグレーション（0001〜0017）

## データについて

- 個人の食事ログ・目標値などの実データは含まない（アプリ側の DB にのみ存在する）。
- 食品マスタの初期データは公的な成分表に基づく。
